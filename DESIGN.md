# Design

<!-- impeccable:design-schema 1 -->

## Visual world

An operate-mode GRE workspace modeled on GregMat's product surfaces: a concise cobalt top navigation, white application canvas, dense filter controls, and clear data tables. Learn is a focused course workspace with its library and player in one view; Practice is a filter-first problem browser that opens the selected problem alongside its results.

## Typography

`DM Sans` handles all functional and display text for a fast, product-native reading rhythm. Numbers use tabular figures; KaTeX owns mathematical notation.

## Layout

Desktop uses a single top navigation and a centered, wide canvas. Learn pairs a compact course browser with the active video; Practice pairs filters and a table with the active question. Mobile stacks each workspace without removing the current task.

## Interaction

Selection changes use short fades and line movement. Native video controls remain native. Keyboard shortcuts are advertised, never required.
